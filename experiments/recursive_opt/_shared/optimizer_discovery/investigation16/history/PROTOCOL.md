# Historical replay protocol (exploratory investigation 16)

Written before the new benchmark replays. This does not modify EXP-15 or claim a new
confirmatory comparison. No model calls or production changes are allocated here.

1. Reevaluate the exact nine preserved routing policies on all four original tasks,
   three sequential repeats per policy/task; also evaluate each unchanged template.
   Preserve every score and compare with the historical table, without changing tasks.
2. Recompute the full-menu leave-one-task-out W2 sweep against uniform search, with
   the original bundle default retained. Add a declared fixed-nearest control to
   determine whether the gain requires learned ordering on this particular menu.
   Report this as an informed diagnostic, not a fair replacement for an uninformed
   control on arbitrary unknown problems.
3. Reevaluate every preserved source-valid Probe X candidate on its source and both
   sibling targets. Preserve invalid sentinel values as historical evidence, but
   separate execution validity from objective values in the new analysis.
4. Recheck the two original code-menu surfaces and the type-mismatch guard. Inspect
   single-example structure on the 13 historically probed deterministic bundles.
   No claim about an unexercised optimizer/config knob follows from scoring only.
5. Record repository and external Trace-Bench versions, input hashes, commands,
   timings, and differences. Existing evidence is read-only. Reproduction of the
   same fixtures does not provide fresh generalization evidence.

The scoring calls use the existing real Trace-Bench evaluator. The historical menu
and saved source are reused verbatim. No external-provider or task-generation calls
are permitted. Socket creation is disabled during the replay process.
